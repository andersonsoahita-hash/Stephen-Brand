# Site personnel — Stephen Anderson Soahita

Site statique (HTML/CSS/JS, aucune dépendance à installer).

## Publier sur GitHub Pages
1. Créer un nouveau dépôt GitHub (par ex. `stephen-site`).
2. Envoyer tout le contenu de ce dossier à la racine du dépôt (`index.html`, `img/`, `.nojekyll`).
3. Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
4. Le site est disponible à `https://<ton-pseudo>.github.io/<nom-du-depot>/`.

La page contient `noindex` : les moteurs de recherche ne l'indexent pas.
Pour modifier un texte ou ajouter une affiche : tout est dans le tableau `ROWS` en haut du script de `index.html`.
